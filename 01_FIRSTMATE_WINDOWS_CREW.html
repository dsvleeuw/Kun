Hoe Firstmate Native op Windows Werkt

1. Herdr als Windows Sessie Backend

Native Windows

Op Windows gebruikt Firstmate Herdr (reeds geconfigureerd in home/.config/herdr/config.toml) om per worker een aparte sessie aan te maken. Je kunt tussen workers schakelen met ctrl+b prefix keys.

fm herdr # opent de actieve crew workspaces

2. Geïsoleerde Git Worktrees (Treehouse)

Geen Conflicten

Elke parallelle worker werkt in een eigen submap. Je actieve werkmap blijft onaangeroerd totdat de taak gereed is en goedgekeurd wordt.

3. Token-Efficiënte Supervisie

Zero-Token Sleep

De First Mate pollt niet voortdurend met dure LLM API calls. Een lokale event-watcher wekt de First Mate alleen als er echt een resultaat of beslissing is.
