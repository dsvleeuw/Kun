Stappenplan: Van Zero naar Ultieme Windows Coding Stack

01

Pakketinstallatie via Winget

Alle kern-tools in één geautomatiseerd PowerShell commando

Gereed in bootstrap.ps1
winget install Microsoft.PowerShell wez.wezterm Neovim.Neovim Starship.Starship Hacker.HackFonts
02

Dotfiles Koppeling (Edit-in-Place)

NTFS Directory Junctions verbinden direct met ~/.dotfiles

Gereed in bootstrap.ps1
New-Item -ItemType Junction -Path "$env:LOCALAPPDATA\nvim" -Target "$HOME\.dotfiles\home\.config\nvim"
03
