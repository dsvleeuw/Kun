Stap-voor-stap Installatievolgorde

1

Clone en Voer Bootstrap Uit

Automatische installatie via PowerShell 7 of Windows PowerShell

1 Commando
git clone https://github.com/dsvleeuw/Kun.git "$HOME\.dotfiles"
cd "$HOME\.dotfiles"
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\bootstrap.ps1
2

Open WezTerm

Startmenu > 'WezTerm' of typ wezterm in Run (Win+R)

UI Terminal

WezTerm start automatisch op met 0.8 transparantie, het Hack Nerd Font en laadt je PowerShell 7 profiel met Starship prompt.

3

Start Neovim (lazy.nvim bootstrapping)

Typ nvim en druk op Enter

Editor

De eerste keer bootstrap lazy.nvim alle plugins (Oil, Snacks, Neogit, Diffview, Which-key). Druk op Space e voor de file browser of Space f om bestanden te zoeken.

4

Start Coding Agents (Claude, Pi, Firstmate)

High-agency aliassen en vlootstart

Autonomous
cc # claude --dangerously-skip-permissions
fm start # Firstmate supervisor
5

Review Artefacten met Lavish Editor

Open interactieve HTML bestanden voor annotaties

Visual Review
lavish .\00_OVERZICHT_ARCHITECTUUR.html
